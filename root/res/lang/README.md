# 界面语言文件 / Interface language files

SDR++ CE 通过“语言”模块（模块类型 `change_language`）切换界面语言。
语言文件是普通的 UTF-8 文本（JSON 格式），用记事本、VS Code 等任何文本编辑器都能直接修改。

## 1. 文件名

文件名就是语言标签，使用国际通行的 **BCP 47 / IETF 语言标签**：`语言-地区.json`

| 文件 | 语言 |
|------|------|
| `zh-CN.json` | 简体中文（中国大陆） |
| `en-US.json` | 英语（美国） |
| `ja-JP.json` | 日语（日本） |
| `de-DE.json` | 德语（德国） |
| `fr-FR.json` | 法语（法国） |
| `zh-TW.json` | 繁体中文（台湾） |

语言用 ISO 639 小写代码，地区用 ISO 3166 大写代码，中间用连字符。

## 2. 安装与选择

* 内置语言文件在程序资源目录的 `lang` 文件夹：`<resources>/lang/`
* 用户自己的语言文件放在 `<root>/lang/`（`<root>` 是 SDR++ 的配置目录，即 `config.json` 所在目录）。
  同一个语言标签下，用户目录里的文件优先于内置文件。
* 打开“模块管理器”里的“语言”模块：
  * 下拉框选择语言；
  * “加载语言文件...”选择任意位置的 `.json` 文件，程序会检查后复制到用户语言目录并立即应用；
  * 手动把文件放进用户语言目录后，点“重新加载”即可出现在下拉框里。
* 选择会保存，下次启动自动使用。

## 3. 文件格式

```json
{
  "format": 1,
  "meta": {
    "code": "ja-JP",
    "name": "Japanese (Japan)",
    "native_name": "日本語",
    "author": "你的名字",
    "version": "1.0"
  },
  "strings": {
    "// 注释": "以 // 或 _ 开头的键会被忽略，可以用来写备注",
    "扫描器": {
      "开始": "開始",
      "停止": "停止"
    },
    "确定": "OK"
  }
}
```

* `format`：格式版本，目前是 `1`。
* `meta`：语言信息。`code` 要和文件名一致；`native_name` 是显示在下拉框里的名字；其余可选。
* `strings`：**原文 → 译文** 对照表。
  * **左边（键）是程序里的中文原文，必须和程序里的文字一字不差，不要修改。**
  * **右边（值）是你要显示的文字。**
  * 条目可以用嵌套对象分组（如上面的 `"扫描器": {...}`），分组名本身不参与翻译，只是方便整理。
  * 没有翻译的条目（找不到、值为空、值和原文一样）会继续显示中文原文，所以可以只翻译一部分。

## 4. 制作自己的语言

1. 复制 `zh-CN.json`（原文模板，左右两边相同）或 `en-US.json`，改名为你的语言标签，例如 `ja-JP.json`。
2. 修改 `meta` 里的信息。
3. 只修改每行 **冒号右边** 的文字。
4. 保存为 **UTF-8** 编码（带不带 BOM 都可以），在“语言”模块里加载。

### 必须遵守的规则

* **`%d`、`%s`、`%.1f`、`%02d` 这样的格式符必须保持原样，数量、顺序、类型都要和原文一致。**
  程序把它们当作数字或文字的占位符，写错会导致错位甚至崩溃，所以不一致的条目会被自动忽略，并在“被忽略的翻译条目”里列出。
  要显示百分号写 `%%`。
* `\n` 表示换行，`\"` 表示引号，`\\` 表示反斜杠——JSON 的标准写法。
* JSON 语法：键值之间用冒号，条目之间用逗号，**最后一个条目后面不能有逗号**，引号必须是英文半角 `"`。
  写错时“语言”模块会提示出错的行和列。
* 控件的内部标识（原文里 `##` 之后的部分）不需要也不应该出现在语言文件里。

## 5. 维护工具（开发者）

在源码仓库根目录运行：

```
python3 tools/i18n_tool.py extract          # 列出源码里所有界面原文
python3 tools/i18n_tool.py template         # 重新生成 zh-CN.json
python3 tools/i18n_tool.py update en-US     # 把新增的原文补进 en-US.json（译文为空，待翻译）
python3 tools/i18n_tool.py check            # 检查所有语言文件（缺少的条目、格式符是否一致）
```

新增界面文字时，直接在源码里写中文，然后运行 `update` 把新条目加到各语言文件即可。

## 6. 已知限制

* 翻译发生在界面绘制层，按“整条文字”匹配。程序运行时用字符串拼接出来的句子（例如“加载失败: ”+ 错误信息）
  整句不会匹配，会保持中文；`extract` 会标出这类“[拼接]”原文。
* 通过 `ImDrawList::AddText` 直接画出的文字（如瀑布图频率刻度）不经过翻译层。
* 字体需要包含目标语言的字形。程序默认字体含简体中文常用字、西里尔字母和拉丁字母；日文、韩文、阿拉伯文等需要另外提供字体。
